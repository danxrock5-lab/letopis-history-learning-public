# Летопись — история России, 7 класс

Адаптивный школьный сайт для изучения истории России: светлая яркая тема, понятная навигация, кабинеты ученика и учителя, проверочные работы и олимпиады, автоматическое оценивание, конспекты и учительская аналитика. Сайт подходит для телефонов, планшетов и компьютеров.

## Запуск

```bash
npm install
npm run dev
```

Production-сборка:

```bash
npm run build
npm run preview
```

## Демо-доступы

| Роль | Имя | Пароль |
| --- | --- | --- |
| Учитель | Учитель | `teacher-demo` |
| Ученик | Ученик 1 | `student1-demo` |
| Ученик | Ученик 2 | `student2-demo` |
| Ученик | Ученик 3 | `student3-demo` |

Это демонстрационный frontend без сервера авторизации: учётные записи находятся в клиентском коде, а результаты и выбранная тема хранятся в localStorage текущего браузера. Пароли ниже — только локальные демонстрационные; для реального использования понадобится серверная авторизация и база данных.

## Учебная программа

Темы подготовлены как обзор первой четверти по Смутному времени и началу правления Романовых. Конкретное распределение глав по четвертям зависит от издания учебника и школьного календарно-тематического планирования. Сайт не воспроизводит текст учебника; конспекты и задания написаны кратко и своими словами.

Официальные ориентиры:

- [Единое содержание общего образования — рабочие программы](https://edsoo.ru/rabochie-programmy/)
- [Федеральный государственный образовательный стандарт](https://edsoo.ru/)
- [Федеральный перечень учебников](https://fpu.edu.ru/)
- [Президентская библиотека](https://www.prlib.ru/)
